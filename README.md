# 🩺 DiagnoFast

DiagnoFast is a full-stack, AI-powered medical diagnosis application. It allows users to describe their symptoms in plain English (Natural Language), and uses a custom-trained Machine Learning model to predict probable diseases. The application includes secure user authentication and automatically saves a history of all diagnoses to a database.

## 🧠 How the AI Works

Unlike traditional symptom checkers that use clunky checkboxes, DiagnoFast uses **Natural Language Processing (NLP)**. 
1. The user types a sentence (e.g., *"I have a severe headache and my vision is blurry."*).
2. The Flask API cleans the text, extracts keywords, and uses a **TF-IDF Vectorizer** to convert the text into mathematical vectors.
3. A **LinearSVC (Support Vector Classifier)** predicts the top 3 probable diseases.
4. The API calculates a confidence score based on the mathematical gap between the #1 and #2 predictions.

**Overcoming Data Bias (The Engineering Fix):**
During development, the model heavily over-predicted "Diabetes" for generic symptoms due to class imbalance in the dataset. To solve this, the training pipeline was upgraded to use `class_weight='balanced'`, and the dataset was manually augmented with accurate medical descriptions for Migraines and COVID-19 to teach the model real-world context.

## 🛡️ Key Features
* **Secure Auth:** Passwords hashed with bcrypt, protected routes via JWT.
* **Input Validation:** Rejects non-medical text (like "hi") and short inputs before hitting the AI model.
* **Diagnosis History:** Every prediction is saved to MongoDB and linked to the user's profile.
* **Modern UI:** Fully responsive, beautiful dark-mode interface.

## ⚙️ How to Run Locally

### Prerequisites
* Node.js installed
* Python 3.9+ installed
* MongoDB installed and running locally on port `27017`

### 1. Clone the repository

```bash
git clone https://github.com/KnightMaresss/DiagnoFast.git
cd DiagnoFast
```

2. Install Dependencies
You need to install packages for both Node and Python.

```bash
# Install backend/frontend dependencies
npm install
cd frontend && npm install && cd ..

# Install Python dependencies
cd ml_model
pip install -r requirements.txt
```

3. Train the AI Model (Important!)
Because the .pkl model file is generated locally, you must train the model before running the app:

```bash
# While inside the ml_model folder
python train_nlp.py
```
(You should see an accuracy report and a new nlp_model.pkl file created).

4. Environment Variables
Create a .env file in the root directory and add your secret key:

```bash
JWT_SECRET=your_super_secret_key_here
```

5. Start the Application
We use concurrently to start the React frontend, Node backend, and Python Flask API all at once. From the root directory, run:

```bash
npm start
```
•	Frontend: http://localhost:5173
•	Backend: http://localhost:5000
•	AI API: http://localhost:8001
